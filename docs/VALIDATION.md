## Банковский сценарий — 13 ноября 2026 года

Добавлен второй сценарий продуктовой команды банковского приложения. Исходное демо дизайн-системы сохранено. Сессия независимого коллеги ещё не проводилась.

- Сборка успешна. `npm test`: 17/17, включая восемь новых проверок обоих наборов, их справочников, источников, истории замены, метрик и выбора сценария по URL.
- В браузере переключатель открывает `?demo=bank#/meetings`. Возврат к дизайн-системе показывает прежние восемь встреч и компонентный справочник; повторное переключение возвращает банковские записи. Ключ исходных сохранений не изменён, банковский ключ отдельный.
- Основной путь проверен: «Проследить решение» → `DEC-B05` → `27:45` / `bank-m4-s4` → возврат к решению → прежнее `DEC-B01`. Источник выделен, причина видна, старое решение имеет статус «Заменено» и переход к текущему. У действующего решения показана связь с `DEMO-201`.
- В итогах встречи видны семь участников и разные роли. Поиск «исследователь» возвращает три подходящие встречи.
- Аналитика показывает у переводов три встречи и одну проблему. Переход из «Истории операций → Без связи с Jira» открывает одно действие с тем же фильтром; диалог сравнения содержит разные описания и критерии `DEMO-202` и `DEMO-203`.
- Пример импорта относится к переводам, мобильной команде и iOS. Новые опциональные поля участников и этапа проверяются перед импортом.
- Светлая и тёмная темы проверены визуально. Тёмный scrim остаётся `rgba(0, 0, 0, 0.8)`.
- Исправлено наблюдаемое наложение длинных фильтров: `min-width: 0` у контейнера поля. На desktop измеренные ширины каждого фильтра и его control совпадают (170 px).
- Адаптивный прогон в same-origin iframe: на ширине 390 px таблица имеет 341 px без внутреннего переполнения; на 879 px — 750 px. Шапка в обоих случаях 48 px. Рейл 64 px, пять кнопок 40×40 px.
- На мобильном экране меню получает фокус на текущем разделе; Escape возвращает его кнопке открытия. Дравер занимает 390 px, тело имеет отдельную прокрутку, края не выходят за экран.
- В отфильтрованном журнале ошибок для адреса приложения ошибок не найдено. Данные встреч и решения при UI-проверке не редактировались. Временный адаптивный стенд удалён перед публикацией.

По комментарию пользователя со страницы «Интеграции» удалён весь технический блок с описанием реализации интерфейса, включая ссылки и восстановление демонстрационных данных. Сборка `npm run build` проходит. В браузере проверена страница в тёмной теме: карточки агента и Jira, а также требования к живому пилоту отображаются; удалённых элементов нет. Скриншот: [страница интеграций](assets/decision-journal-integrations-clean.jpg).


## Нейтральные названия компонентов

Локальный набор компонентов перенесён в `vendor/ui`; CSS-классы и переменные используют префикс `ui-`, типы — `Ui`. Заголовок вкладки: «Журнал решений». Метаданные описывают задачи продукта. Генератор темы сохраняет прежние значения токенов; сборка проходит. В браузере проверены светлая и тёмная темы, открытие и закрытие панели встречи. Сканирование актуальных исходников, документации и готовой сборки не находит прежних брендовых названий. Старый скриншот с техническим бейджем удалён. Текущий вид: [список встреч](assets/team-memory-current.jpg).
